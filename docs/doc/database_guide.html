Database Architecture & Data Layer

The database is designed around simplicity, human readability, and version control integrity. It uses structured ASCII pipe-delimited files for taxonomic lists and standard comma-separated values (CSV) for relational registries.

File Path Format Description
database/cycle.txt Plaintext Current GTAC proposal cycle number (e.g. 52).
database/affiliations.txt Pipe ASCII Observatory and university directory (AFF_XXX | Name).
database/expertise.txt Pipe ASCII Radio astronomy and physics research domains (EXP_XX | Topic).
database/career_status.txt Pipe ASCII Academic career stages (CAR_XX | Stage).
database/Referee_database_A.csv CSV Primary registry of verified and suggested referees.
database/form_submissions.csv CSV Immutable audit log recording every registration and recommendation.
dev/db_data.js JavaScript Auto-generated client export bundle for standalone offline execution.

Cycle Configuration (cycle.txt)

Stores the active GTAC proposal cycle. 

52

Characteristics:

  • Instant Propagation: Updating the integer in database/cycle.txt immediately updates the Question 6 label in the web form and the backend REST API (/api/cycle) without requiring server restarts.
  • Convenience Symlinks: Symlinked to cycle.txt (project root) and dev/cycle.txt for transparent access across all directory contexts.

ASCII Pipe-Delimited Taxonomies

All controlled vocabularies are stored as human-readable pipe-delimited ASCII files with the standard format: 

ID | Description

1. Affiliations Directory (affiliations.txt)

Contains 30+ observatories, institutions, and universities. Uses sequential identifier prefix AFF_. 

AFF_001 | National Centre for Radio Astrophysics (NCRA-TIFR), Pune
AFF_002 | Inter-University Centre for Astronomy and Astrophysics (IUCAA), Pune
AFF_003 | Raman Research Institute (RRI), Bengaluru
AFF_004 | Indian Institute of Science (IISc), Bengaluru
AFF_005 | Tata Institute of Fundamental Research (TIFR), Mumbai
AFF_006 | Indian Institute of Astrophysics (IIA), Bengaluru
AFF_007 | Physical Research Laboratory (PRL), Ahmedabad
...
Dynamic Expansion: When a user enters a new institution via "+ Others", the system automatically generates the next sequential identifier (e.g. AFF_031) and appends the institution to this file.

2. Expertise Taxonomy (expertise.txt)

Covers 18 specialized radio astronomy and astrophysics domains. Uses identifier prefix EXP_. 

EXP_01 | Pulsars, Transients and Fast Radio Bursts
EXP_02 | Cosmology, Epoch of Reionization and 21cm
EXP_03 | Neutral Hydrogen (HI) in Galaxies
EXP_04 | Active Galactic Nuclei, Jets and Quasars
EXP_05 | Galaxy Clusters, Relics, Halos and Cosmic Rays
EXP_06 | Star Formation, Interstellar Medium and Molecular Clouds
EXP_07 | Magnetic Fields and Polarimetry
...

3. Career Status Categories (career_status.txt)

Categorizes researcher seniority levels using prefix CAR_. 

CAR_01 | Undergraduate Student
CAR_02 | PhD Student / Graduate Student
CAR_03 | Post-Doctoral Fellow
CAR_04 | Faculty Member (Assistant / Associate / Full Professor)
CAR_05 | Scientist / Staff Astronomer
CAR_06 | Engineer / Technical Staff
CAR_07 | Others

Primary Referee Registry (Referee_database_A.csv)

The authoritative registry containing all prospective and verified peer reviewers for GTAC proposals.

CSV Schema Definition:

Column Header Format / Type Example Value Description
unique_id REF_XXXX REF_0001 Unique sequential identifier assigned to each referee.
referee_name String (Cleaned) Yashwant Gupta Full name with all honorific titles (Dr, Prof) stripped.
email Email String ygupta@ncra.tifr.res.in Primary academic contact email.
affiliation AFF_XXX or String AFF_001 Institution foreign key or custom affiliation label.
expertise Semicolon List EXP_01;EXP_14 Delimited list of matching expertise domain IDs.
career_status CAR_XX CAR_04 Seniority classification foreign key.
referee_status verified | suggested verified Editorial verification status within GTAC.
available true | false true Willingness / availability flag for review assignments.

De-duplication & Update Resolution:

  1. Exact Email Match: If incoming referee email matches an existing record, the record is updated rather than duplicated.
  2. Exact Name Match: Title-stripped name comparison.
  3. Half-Initials Match: Fuzzy match on surname + initials (e.g. Y. Gupta matches Yashwant Gupta).
  4. Self-Entry Priority: When a submitter submits their own profile, their entered data updates their record authoritatively.

Submissions Audit Log (form_submissions.csv)

Maintains an immutable record of every completed form submission.

Column Header Type Description
submission_id SUB_ Unique submission identifier generated at submission time.
timestamp ISO-8601 UTC Full timestamp of submission (e.g. 2026-09-11T12:48:08Z).
user_name String Cleaned submitter name.
user_email String Submitter email address.
user_affiliation AFF_XXX Submitter affiliation ID.
user_career_status CAR_XX Submitter career status ID.
user_expertise Semicolon List Submitter expertise domain IDs.
review_this_cycle yes | no Willingness for the current GTAC cycle.
review_future_cycles yes | no Willingness for future GTAC cycles.
suggested_referees JSON Array List of REF_XXXX identifiers submitted in this session.

Offline Export Bundle (db_data.js)

To allow the form to run completely standalone when opened via file:// without local web server requirements, dev/server.py automatically exports the disk database to dev/db_data.js: 

// Auto-generated database export for standalone file:// support
window.GTAC_DATABASE = {
  "cycle": "52",
  "affiliations": [ ... ],
  "expertise": [ ... ],
  "career_status": [ ... ],
  "referees": [ ... ]
};

This eliminates browser CORS restrictions and avoids "Load failed" errors.
